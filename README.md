# Linked-list Queue in C++

A console exercise implementing enqueue, dequeue and traversal with linked nodes.

## Scope

The implementation is instructional; dequeued nodes are not explicitly freed. It is not a production container or a verified memory-safe implementation.

## Technology / Material

C++ · CMake

## Repository guide

- [main.cpp](main.cpp)
- [CMakeLists.txt](CMakeLists.txt)

## Getting started / Reproducibility

Inspect `main.cpp`; use a compatible C++ compiler or the included CMake configuration to build a local executable.
